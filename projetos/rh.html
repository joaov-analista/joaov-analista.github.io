Contexto do Projeto

Este projeto simula um cenário real de People Analytics: uma base de RH com dados cadastrais, folha de pagamento e registros de ausência de 950 colaboradores entre 2021 e 2026. O objetivo foi identificar os fatores que mais influenciam turnover e absenteísmo — transformando dados operacionais de RH em alertas antecipados que podem orientar ações de retenção antes que o colaborador decida sair.

O tratamento de dados em Python envolveu a limpeza e padronização de 5 tabelas relacionadas — dimensões de área, calendário e funcionário; fatos de ausências e folha de pagamento — com verificação de nulos, conversão de tipos, checagem de consistência entre datas (nascimento, admissão, demissão) e detecção de outliers por método IQR. Esse processo revelou 1.657 registros de horas extras fora do padrão, concentrados em áreas específicas.

No Power BI, foram construídas 12 medidas DAX (turnover, absenteísmo, custo por colaborador, comparativos ano a ano) distribuídas em 4 páginas analíticas com foco em diferentes perspectivas do problema de RH.

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sn

# importando os arquivos csv
dim_area = pd.read_csv("C:\\Projetos banco de dados\\projeto RH\\dim_area.csv")
dim_calendario = pd.read_csv("C:\\Projetos banco de dados\\projeto RH\dim_calendario.csv")
dim_funcionario = pd.read_csv("C:\\Projetos banco de dados\\projeto RH\\dim_funcionario.csv")
fat_ausencias = pd.read_csv("C:\\Projetos banco de dados\\projeto RH\\fact_ausencias.csv")
fat_folha = pd.read_csv("C:\\Projetos banco de dados\\projeto RH\\fact_folha.csv")

dfs = [dim_area, dim_funcionario, dim_calendario, fat_ausencias, fat_folha]

# ler algumas linhas do csv para verificar a formatação das bases
for i in dfs:
    print(i.head().to_string())

# verificar se há nulos nas bases
for i in dfs:
    print(i.isnull().sum())

# formatar o tipo de dado das bases
data_funcionarios = ["data_nascimento", "data_admissao", "data_demissao"]
    
for col in data_funcionarios:
    dim_funcionario[col] = pd.to_datetime(dim_funcionario[col])
    
dim_calendario["data"] = pd.to_datetime(dim_calendario["data"])
fat_ausencias["data"] = pd.to_datetime(fat_ausencias["data"])
fat_folha["mes_referencia"] = pd.to_datetime(fat_folha["mes_referencia"])

for i in dfs:
    print("tipos de dados:\n", i.dtypes)

# verificar se há outliers nos registros
# tabela de funcionarios
# out em data de nascimento
n_min = dim_funcionario["data_nascimento"].min()
n_max = dim_funcionario["data_nascimento"].max()
print(f"Data de nascimento Min: {n_min} e Max: {n_max}")

# out em data de admissão e demissao
a_min = dim_funcionario["data_admissao"].min()
a_max = dim_funcionario["data_admissao"].max()
print(f"Data de admissão Min {a_min} e Max {a_max}")

d_min = dim_funcionario["data_demissao"].min()
d_max = dim_funcionario["data_demissao"].max()
print(f"Data de demissão Min {d_min} e Max {d_max}")

# nascimento depois da admissao
inconsistencia_idade = dim_funcionario[dim_funcionario["data_nascimento"] >= dim_funcionario["data_admissao"]]
print("Datas de nascimento maior ou igual  que a data de admissão: ", inconsistencia_idade) 

# demissao antes da admissao
inconsistencia_admisao = dim_funcionario[dim_funcionario["data_demissao"] <= dim_funcionario["data_admissao"]]
print("Data de demissão antes da data de demissão: ", inconsistencia_admisao)

# criando coluna de idade funcionarios
data_referencia = pd.Timestamp.today().normalize()
dim_funcionario["idade"] = (data_referencia - dim_funcionario["data_nascimento"]).dt.days // 365

# verificar as idades funcionarios
i_min = dim_funcionario["idade"].min()
i_max = dim_funcionario["idade"].max()
print(f"Idade Min: {i_min} e Max: {i_max}")

# outliers em salario
print("Estatisticas de salário:")
dim_funcionario["salario_atual"].describe()

# os 5 mariores salarios 
dim_funcionario.nlargest(5, "salario_atual")

# tabela de ausencias
# datas min e max
ausencia_min = fat_ausencias["data"].min()
ausencia_max = fat_ausencias["data"].max()
print(f"Data de ausencia Min: {ausencia_min} e Max: {ausencia_max}")

# estatisticas de horas perdidas
print("Estatisticas da coluna de horas perdidas: ")
fat_ausencias["horas_perdidas"].describe()

# tabela folha
# calcular o quartil de horas extras
q1 = fat_folha["horas_extras_qtd"].quantile(0.25)
q3 = fat_folha["horas_extras_qtd"].quantile(0.75)
IQR = q3 - q1

limite_baixo = q1 - 1.5 * IQR
limite_alto = q3 + 1.5 * IQR

outliers = fat_folha[
    (fat_folha["horas_extras_qtd"] < limite_baixo) |
    (fat_folha["horas_extras_qtd"] > limite_alto)
]
print(f"{len(outliers)} outliers encontrados")
print(outliers)

# grafico de custo por area
plt.figure(figsize=(12, 6))
sn.boxplot(data=fat_folha, y="custo_total" ,x="area", hue="area", palette="Set2", legend=False)
plt.title("Custo total por área", fontsize=14, fontweight="bold")
plt.xlabel("Área")
plt.ylabel("Custo total (R$)")
plt.xticks(rotation=30, ha="right")
plt.tight_layout()
plt.show()

'''
COMO LER O GRAFICO
as barras são o meio dos dados
dentro das barras, a linha dentro das barras é a mediana 
abaixo da linha é o Q1 (25% dos dados)
acima da linha é o Q3 (75% dos dados)
a altura da caixa é o IQR (intervalo do quartil)

as linhas fora das barras são os limites do IQR (Q1 - 1.5 x IQR e Q3 + 1.5 x IQR)
as  bolinhas fora das barras são os outliers, que ficaram fora da faixa de IQR esperada
'''
# consulta de outliers detectados
fat_folha[fat_folha["custo_total"] > 15000]

# salvar as bases tratadas
bases = {
    "dim_funcionario": dim_funcionario,
    "dim_area": dim_area,
    "dim_calendario": dim_calendario,
    "fat_ausencias": fat_ausencias,
    "fat_folha": fat_folha
}

for nome, df in bases.items():
    df.to_csv(f"{nome}_tratato_python.csv", index=False, encoding="utf-8-sig")

Insights do Projeto

2,5 → 4,5 eventos/mês
Absenteísmo é preditor antecipado de desligamento
A frequência de ausências por colaborador salta de 2,5 para 4,5 eventos por mês nos dois meses que antecedem o desligamento — um sinal de alerta que pode orientar ações de retenção antes que a decisão de sair seja tomada.
1.657 outliers
Sobrecarga de horas extras concentra o maior turnover
Logística e Operações lideram simultaneamente em horas extras e em turnover — sugerindo que a sobrecarga de trabalho é um fator direto de saída nessas áreas. Os 1.657 registros fora do padrão (IQR) estão concentrados exatamente nessas equipes.
3 áreas acima da meta
Operações, Logística e Comercial excedem o turnover-alvo
Essas três áreas superam a meta de turnover definida em todos os anos analisados, enquanto TI, Financeiro e Jurídico permanecem dentro ou próximos da meta — revelando que o problema é estrutural em áreas operacionais, não generalizado.
218 de 399 saídas
Maioria das saídas é voluntária — o problema é retenção
218 dos 399 desligamentos foram iniciados pelo próprio colaborador. Isso direciona a investigação para clima organizacional, remuneração e sobrecarga — não para reestruturação ou corte de custos — e indica que a empresa tem poder de agir preventivamente.
