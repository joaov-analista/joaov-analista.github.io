Contexto do Projeto

Este projeto simula um cenário real de People Analytics: uma base de RH com dados cadastrais, folha de pagamento e registros de ausência de 950 colaboradores entre 2021 e 2026. O objetivo foi identificar os fatores que mais influenciam turnover e absenteísmo — transformando dados operacionais de RH em alertas antecipados que podem orientar ações de retenção antes que o colaborador decida sair.

O tratamento de dados em Python envolveu a limpeza e padronização de 5 tabelas relacionadas — dimensões de área, calendário e funcionário; fatos de ausências e folha de pagamento — com verificação de nulos, conversão de tipos, checagem de consistência entre datas (nascimento, admissão, demissão) e detecção de outliers por método IQR. Esse processo revelou 1.657 registros de horas extras fora do padrão, concentrados em áreas específicas.

No Power BI, foram construídas 12 medidas DAX (turnover, absenteísmo, custo por colaborador, comparativos ano a ano) distribuídas em 4 páginas analíticas com foco em diferentes perspectivas do problema de RH.

Código Utilizado

# ================================================
# ETL & LIMPEZA — PEOPLE ANALYTICS (RH)
# Autor: João Vítor de Freitas | Python + Pandas
# 5 tabelas: dim_area, dim_calendario, dim_funcionario,
#            fato_ausencias, fato_folha
# ================================================

import pandas as pd
import numpy as np

# ── 1. Carregamento das tabelas ──────────────────
dim_area        = pd.read_csv('data/dim_area.csv')
dim_calendario  = pd.read_csv('data/dim_calendario.csv')
dim_funcionario = pd.read_csv('data/dim_funcionario.csv')
fato_ausencias  = pd.read_csv('data/fato_ausencias.csv')
fato_folha      = pd.read_csv('data/fato_folha.csv')

# ── 2. Verificação de nulos em todas as tabelas ──
for nome, df in {
    'dim_area':        dim_area,
    'dim_funcionario': dim_funcionario,
    'fato_ausencias':  fato_ausencias,
    'fato_folha':      fato_folha,
}.items():
    nulos = df.isnull().sum()
    nulos = nulos[nulos > 0]
    if not nulos.empty:
        print(f"\n[{nome}] Nulos encontrados:\n{nulos}")
    else:
        print(f"[{nome}] Sem nulos.")

# ── 3. Conversão de tipos — dim_funcionario ──────
colunas_data = ['dt_nascimento', 'dt_admissao', 'dt_demissao']
for col in colunas_data:
    dim_funcionario[col] = pd.to_datetime(
        dim_funcionario[col], errors='coerce'
    )

# ── 4. Checagem de consistência entre datas ──────
# Admissão deve ser posterior ao nascimento
invalidos_admissao = dim_funcionario[
    dim_funcionario['dt_admissao'] <= dim_funcionario['dt_nascimento']
]
print(f"\nAdmissões inválidas (antes do nascimento): "
      f"{len(invalidos_admissao)}")

# Demissão deve ser posterior à admissão (quando preenchida)
ativos = dim_funcionario['dt_demissao'].notna()
invalidos_demissao = dim_funcionario[
    ativos &
    (dim_funcionario['dt_demissao'] <= dim_funcionario['dt_admissao'])
]
print(f"Demissões inválidas (antes da admissão): "
      f"{len(invalidos_demissao)}")

# ── 5. Padronização de strings ───────────────────
dim_funcionario['nm_funcionario'] = (
    dim_funcionario['nm_funcionario']
    .str.strip()
    .str.title()
)
dim_area['nm_area'] = dim_area['nm_area'].str.strip().str.upper()

# ── 6. Calcular tempo de casa (meses) ───────────
hoje = pd.Timestamp.today()
dim_funcionario['meses_de_casa'] = dim_funcionario.apply(
    lambda r: (
        (r['dt_demissao'] - r['dt_admissao']).days // 30
        if pd.notna(r['dt_demissao'])
        else (hoje - r['dt_admissao']).days // 30
    ), axis=1
)

# ── 7. Classificar tipo de desligamento ──────────
# Saída voluntária = colaborador pediu demissão
dim_funcionario['tipo_saida'] = dim_funcionario['motivo_saida'].map({
    'Pedido de demissão': 'Voluntária',
    'Demissão sem justa causa': 'Involuntária',
    'Demissão com justa causa': 'Involuntária',
    'Acordo': 'Involuntária',
    'Aposentadoria': 'Voluntária',
}).fillna('Ativo')

saidas = dim_funcionario[dim_funcionario['tipo_saida'] != 'Ativo']
print(f"\nTotal de desligamentos: {len(saidas)}")
print(saidas['tipo_saida'].value_counts())

# ── 8. Export para Power BI ──────────────────────
dim_funcionario.to_csv('output/dim_funcionario_tratada.csv',
                       index=False, encoding='utf-8-sig')
fato_ausencias.to_csv('output/fato_ausencias_tratada.csv',
                      index=False, encoding='utf-8-sig')
fato_folha.to_csv('output/fato_folha_tratada.csv',
                  index=False, encoding='utf-8-sig')
print("\nArquivos exportados com sucesso.")

# DETECÇÃO DE OUTLIERS & EDA — PEOPLE ANALYTICS
# Autor: João Vítor de Freitas | Python + Pandas
# Método: IQR (Interquartile Range)
# ================================================

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style='whitegrid')
plt.rcParams['figure.dpi'] = 120

fato_folha      = pd.read_csv('output/fato_folha_tratada.csv')
fato_ausencias  = pd.read_csv('output/fato_ausencias_tratada.csv')
dim_funcionario = pd.read_csv('output/dim_funcionario_tratada.csv')

# ── 1. Detecção de outliers em horas extras (IQR) ─
Q1 = fato_folha['horas_extras'].quantile(0.25)
Q3 = fato_folha['horas_extras'].quantile(0.75)
IQR = Q3 - Q1
limite_sup = Q3 + 1.5 * IQR

outliers_he = fato_folha[fato_folha['horas_extras'] > limite_sup]
print(f"Outliers de horas extras detectados: {len(outliers_he):,}")
print(f"Limite superior IQR: {limite_sup:.1f}h")

# ── 2. Outliers por área ──────────────────────────
outliers_por_area = (
    outliers_he
    .groupby('cd_area')['horas_extras']
    .agg(qtd='count', media='mean')
    .sort_values('qtd', ascending=False)
    .head(5)
)
print("\nTop 5 áreas com mais outliers de horas extras:")
print(outliers_por_area)

# ── 3. Absenteísmo pré-demissão ──────────────────
# Calcular eventos de ausência por colaborador por mês
ausencias_mensais = (
    fato_ausencias
    .groupby(['cd_funcionario', 'ano_mes'])['id_ausencia']
    .count()
    .reset_index(name='eventos_mes')
)

# Identificar os 2 meses antes do desligamento
demitidos = dim_funcionario[
    dim_funcionario['dt_demissao'].notna()
][['cd_funcionario', 'dt_demissao']].copy()
demitidos['dt_demissao'] = pd.to_datetime(demitidos['dt_demissao'])
demitidos['mes_demissao'] = demitidos['dt_demissao'].dt.to_period('M')

# Calcular janela de alerta (meses -2 e -1 antes da saída)
ausencias_mensais['ano_mes'] = pd.PeriodIndex(
    ausencias_mensais['ano_mes'], freq='M'
)
merged = ausencias_mensais.merge(demitidos, on='cd_funcionario')
merged['meses_antes_saida'] = (
    merged['mes_demissao'] - merged['ano_mes']
).apply(lambda x: x.n)

pre_demissao = merged[merged['meses_antes_saida'].between(1, 2)]
baseline     = merged[merged['meses_antes_saida'] > 6]

media_pre  = pre_demissao['eventos_mes'].mean()
media_base = baseline['eventos_mes'].mean()
print(f"\nMédia de eventos/mês (baseline):      {media_base:.1f}")
print(f"Média de eventos/mês (pré-demissão):  {media_pre:.1f}")
print(f"Aumento: +{((media_pre/media_base)-1)*100:.0f}%")

# ── 4. Visualização: absenteísmo × meses para saída ─
resumo = (
    merged[merged['meses_antes_saida'] <= 12]
    .groupby('meses_antes_saida')['eventos_mes']
    .mean()
    .sort_index(ascending=False)
)
fig, ax = plt.subplots(figsize=(10, 4))
ax.plot(resumo.index, resumo.values,
        marker='o', color='#7C3AED', linewidth=2.5)
ax.axvline(2, color='#EF4444', linestyle='--',
           linewidth=1.5, label='Janela de alerta')
ax.invert_xaxis()
ax.set_xlabel('Meses antes do desligamento')
ax.set_ylabel('Média de eventos de ausência/mês')
ax.set_title('Absenteísmo cresce nos meses que antecedem o desligamento',
             fontsize=13, fontweight='bold')
ax.legend()
plt.tight_layout()
plt.savefig('output/absenteismo_pre_demissao.png', bbox_inches='tight')
plt.show()

Insights do Projeto

2,5 → 4,5 eventos/mês
Absenteísmo é preditor antecipado de desligamento
A frequência de ausências por colaborador salta de 2,5 para 4,5 eventos por mês nos dois meses que antecedem o desligamento — um sinal de alerta que pode orientar ações de retenção antes que a decisão de sair seja tomada.
1.657 outliers
Sobrecarga de horas extras concentra o maior turnover
Logística e Operações lideram simultaneamente em horas extras médias e em turnover — sugerindo que a sobrecarga de trabalho é um fator direto de saída nessas áreas. Os 1.657 registros fora do padrão (IQR) estão concentrados exatamente nessas equipes.
3 áreas acima da meta
Operações, Logística e Comercial excedem o turnover-alvo
Essas três áreas superam a meta de turnover definida em todos os anos analisados, enquanto TI, Financeiro e Jurídico permanecem dentro ou próximos da meta — revelando que o problema é estrutural em áreas operacionais, não generalizado.
218 de 399 saídas
Maioria das saídas é voluntária — o problema é retenção
218 dos 399 desligamentos foram iniciados pelo próprio colaborador. Isso direciona a investigação para clima organizacional, remuneração e sobrecarga — não para reestruturação ou corte de custos — e indica que a empresa tem poder de agir preventivamente.
